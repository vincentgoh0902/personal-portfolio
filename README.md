# Vincent Goh · Portfolio

My personal portfolio: internships, projects and education.

**Live:** _coming soon_

Built with [Astro](https://astro.build) and Tailwind CSS. It ships as static HTML with a few lines of JavaScript, so it loads fast on phones.

## Run locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

## Editing content

All text (experience, projects, education, links) is in [`src/data/site.ts`](src/data/site.ts).
Project images go in `src/assets/` and are optimised to WebP at build time.
